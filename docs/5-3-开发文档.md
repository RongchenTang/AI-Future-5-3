  - 迭代过程

## 第二部分 · 课件（网页版 PPT）实现

### 2.1 技术路线
- 纯 HTML + CSS + JavaScript，无框架、无构建步骤；双击 `index.html` 即可本地打开。
- 托管：GitHub Pages（仓库 `main` 分支根目录）。推送后约 1–2 分钟生效。
- 字体全部本地打包（不依赖 Google Fonts，国内可用）。
- 课件本身就是「三件套」的教学示例。

### 2.2 文件结构
```
index.html            19 屏课件的全部结构和文字
css/style.css         全部样式（设计变量、各屏组件、响应式）
js/deck.js            翻页、侧边目录、文件夹目录、复制与提示等通用工具
js/lab.js             五条设计原则（03）与交互实验室（04）
js/studio.js          第 0 步隐喻卡、提示词工作台、修改指令卡、能力盘点提示词
fonts/                子集化字体 + fonts.css
assets/test-qr.svg    指向测试页的二维码
test/                 职业之书测试（独立子站，见第三部分）
download/             离线安装包
docs/                 设计说明、开发文档
styles/ demo/         风格样稿与原型（存档，不参与课件）
```
脚本加载顺序：`deck.js` → `lab.js` → `studio.js`。后两个依赖 `deck.js` 里的 `$`、`$$`、`pad`、`copyText`、`toast`，`studio.js` 依赖 `lab.js` 里的 `esc`。

### 2.4 翻页与导航（`js/deck.js`）
- **每一屏**是一个 `<section class="screen">`，属性：
  - `id`：跳转目标，如 `s-lab1`
  - `data-title`：标题（侧栏、翻页纸上显示）
  - `data-no`：编号，如 `03`
  - `data-group`：可选，同组的屏在侧栏里折叠成子项
- **翻页**：
  - `→` / `PageDown` / 空格 / 翻页笔：`next()`。当前屏没看完先在屏内滚动 75%，看完再翻页。
  - `←` / `PageUp`：`prev()`。屏内已滚动就先回顶部，否则翻回上一屏。
  - 翻页动画：`.turn` 遮罩纸从右侧折入（0.42s），中途瞬移滚动，再向左折出（0.46s）。手机和「减少动态效果」设置下改为平滑滚动。
- **侧边目录**：由各屏的 `data-*` 自动生成，滚动时高亮当前屏。
- **文件夹目录**：`FOLDER` 数组定义 7 张纸（标签、英文名、颜色、跳转目标）。
  - 点黄色封面打开
  - 点任意一张纸 → `goToId()`
  - 拖动旋转（`--rx` / `--ry`），区分拖动和点击
- **新增一屏的方法**：在 `index.html` 合适位置加一个 `section.screen`，写好四个 `data-*` 属性即可，导航会自动更新。若要出现在文件夹里，再改 `FOLDER`。

### 2.5 各屏实现要点
| 屏 | id | 实现要点 |
|---|---|---|
| 封面 | `s-cover` | 纯 HTML/CSS 叠放卡片 |
| 00 今日目录 | `s-folder` | 3D 文件夹：`.rig` 用 `preserve-3d`；尺寸按视口高度 `--SW: min(620px, 72vw, (100vh-210px)/1.12)` |
| 01 职业之书 | `s-book` | 二维码 SVG（Python `qrcode` 生成），链接 `test/` |
| 02 案例 | `s-cases` | 5 张外链卡片 + 观察三问 |
| 04-1 开关实验 | `s-lab1` | `.sw` 切换 `.on`；CSS 关闭时移除 `.styled`，示例页面回到浏览器默认样式（`all: revert`）；HTML 关闭时显示空白；JS 关闭时按钮点击无反应 |
| 04-2 点哪看代码 | `s-lab2` | 元素带 `data-part`；`LAB2_HTML` / `LAB2_CSS` 为代码行与部件的对应表，悬停或点击时高亮对应行 |
| 04-3 动手改一改 | `s-lab3` | 控件改写 CSS 变量 `--c` `--hs` `--r` `--g` `--hf`；右侧 CSS 代码实时重绘，改动的值闪黄 |
| 04-4 F12 | `s-lab4` | 静态步骤卡 + 一句可供改写的文字 |
| 04-5 小测 | `s-quiz` | `QUIZ` 数组：题目、答案、解释；即时判对错并计分 |
| 课间 | `s-break` | 可勾选清单（CSS `:has(input:checked)` 划线）+ 文件夹结构 |
| 03 五条原则 | `s-rules` | `RULES` 数组，每条包含 `text` / `say` / `controls` / `setup`；示例网站 `siteHTML()` 共用，每条原则通过加类名切换状态：`flat`（层级）、排序 + `pathed`（路径）、`rainbow`（统一）、`messy` + `grid-on`（留白对齐）；3 秒测试用倒计时 + 遮罩 |
| 05 第 0 步 | `s-concept` | `METAPHORS` 数组（8 张隐喻卡）；随机抽卡闪烁 10 次；可自定义；两个选项写入 `concept` 对象 |
| 05 工作台 | `s-studio` | 表单 `input` 事件实时调用 `buildPrompt()`；`mode` 为 `basic` 或 `custom`；学生填写内容用 `⟦⟧` 包裹以便高亮，复制时去掉；空字段显示【待填写】 |
| 05 卡片 & 修改指令 | `s-cards` | `FIXES` 数组，点击即复制 |
| 05 能力盘点 | `s-dig` | 提示词全文来自能力挖掘教练仓库的 `prompt.md` |
| 06 实践 | `s-make` | 9 项自查表，实时计数 |
| 07 作业 | `s-hw` / `s-report` | 静态内容 |
| 08 总结 | `s-end` | 静态内容 |

### 2.6 提示词工作台的生成逻辑
`buildPrompt(v)` 输出五个固定部分；个性模式且勾选「两步」时增加第六部分：

1. **关于我**：昵称、专业年级、定位、能力标签、邮箱
2. **我的项目**：项目 1–3
3. **设计要求**：
   - 基础模式（7+1 条）：视觉定位（票根）、信息层级、用户路径（推荐顺序，可调整）、60-30-10、留白对齐、内容网页化、图片交互、避免 AI 模板感
   - 个性模式（0–8 条）：网站概念（隐喻）、视觉定位（可选 IP 取色）、信息层级、用户路径（可按隐喻重设，但须能找到姓名、专业年级、邮箱）、统一、留白、项目呈现（形式随隐喻）、图片交互、避免模板感
4. **真实性要求**：只用提供的信息；不足处标【待补充】
5. **技术要求**：
   - 单个 index.html
   - 相对路径 `images/`
   - 手机适配
   - 标签页标题用名字
   - 页脚 AI 声明
   - 告知保存方法
6. **（个性模式 + 两步）分两步完成**：先给 3 个方向，再写代码

### 2.7 响应式规则
| 条件 | 变化 |
|---|---|
| 基准 1440×900 | 设计基准 |
| 高度 ≤ 940px | 收紧留白、卡片内边距、代码字号 |
| 高度 ≤ 800px | 侧栏收紧 |
| 宽度 ≤ 1280px | 实验 ③ 和作业页改为两列 |
| 宽度 ≤ 1100px | 侧栏收起为顶栏；多数双栏改单栏 |
| 宽度 ≤ 760px（手机） | 全部单列，普通滚动，隐藏翻页按钮 |

**验收标准**：1366×768、1440×900、1920×1080 下 19 屏均为一屏；手机 390 宽无横向滚动；控制台无报错。

### 2.8 字体打包
| 字体 | 来源 | 处理 |
|---|---|---|
| 霞鹜文楷 | npm `lxgw-wenkai-webfont` | 按页面实际用字子集化，合并为一个 woff2 |
| 思源宋体粗体 | npm `@fontsource/noto-serif-sc`（700） | 同上 |
| Fraunces（400 / 400 斜 / 500 / 600） | npm `@fontsource/fraunces` | 直接使用拉丁字符集 |
| Special Elite | npm `@fontsource/special-elite` | 直接使用 |

子集化流程：
1. 收集 `index.html` 和 `js/*.js` 中出现的所有字符
2. 根据各字体 CSS 里的 `unicode-range` 找出覆盖这些字的分片
3. 用 fontTools 对每个分片做子集，再合并成一个 woff2

**改了课件文字后**：新出现的汉字会暂时显示为系统楷体或宋体，不影响使用；需要时重新执行上述流程，测试页 `test/` 单独打包。所有字体均为 SIL OFL 开源授权。

### 2.9 测试方法（Playwright + Chromium）
- **版面**：四种尺寸逐屏截图，检查屏高是否超出视口、是否有横向滚动、是否有报错。
- **功能**：
  - 文件夹跳转
  - 三个开关
  - 代码高亮
  - 滑块与字体
  - 小测计分
  - 五条原则切换与 3 秒测试
  - 两种模式生成的提示词内容
  - 复制（剪贴板内容不含 `⟦⟧`）
  - 自查表计数
- **离线**：解压离线包，在拦截所有网络请求的情况下打开，检查字体、二维码、跳转和测试页。

## 第三部分 · 职业之书测试（`test/`）

| 项目 | 内容 |
|---|---|
| 理论 | 霍兰德 RIASEC 六型（现实型、研究型、艺术型、社会型、企业型、常规型） |
| 题目 | 18 道生活情境题，每题 4 选项，六型各出现 12 次（计分公平） |
| 计分 | 统计各型选择次数，取前两名为主类型、副类型；第三名与第二名同分时提示 |
| 名称 | 霍兰德原名 + 网感昵称（`script.js` 中 `SHOW_NICKNAME` 可关闭昵称） |
| 交互 | 封面翻开动画；一页一题翻页；选中时手绘圈；「目录 · 改答案」随时跳回；底部圆点可点；答完先进入「交卷前检查」 |
| 结果 | 手写风鉴定书（逐行出现、盖章动画）+ 网站风格票根（风格、60-30-10 配色、首屏重点、结构、可复制的定位提示词）+ 六型得分条 |
| 文件 | `index.html` 结构 / `style.css` 样式 / `data.js` 题目与类型文案 / `script.js` 逻辑 / `fonts/` 子集字体 |
| 修改题目 | 只改 `data.js`；保持每题 4 个选项、六型出现次数相等 |
