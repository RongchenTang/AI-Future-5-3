## 3. 交互与技术

- **纯 HTML + CSS + JavaScript**，无框架，无构建。课件本身就是「三件套」的例子。
- **整屏翻页**：每一节占一屏。按 `→` / `PageDown` / 翻页笔下一页；`←` / `PageUp` 上一页。
  - 如果这一屏内容比屏幕长：按 `→` 先在屏内往下滚，滚到底再翻页，不会出现「没看完就被翻走」。
  - 翻页时一张手账纸从右侧扫过，上面写着下一节标题（约 1 秒）。
  - 鼠标滚轮 / 触摸板也可以直接滚动。
- **响应式**：以 1440×900 为基准设计，检查 1366×768、1920×1080、手机 390 宽。
  - ≤1100px 宽：侧边目录收起为顶栏
  - ≤760px 宽（手机）：单列普通网页，上下滑动
  - 高度 ≤940px：自动收紧留白
- **文件结构**

```
/                 课件（index.html + css/ + js/ + assets/ + fonts/）
/test/            职业之书测试
/docs/            本文档
/styles/ /demo/   风格样稿与原型（存档）
```

## 4. 每一屏的内容

全程使用同一个示例网站 **「小林的个人网站」**（数据分析方向），学生看着同一个页面被拆开、被修改、被变好看。

### 封面
- 标题：网站构建：从内容到数字呈现
- 副标题：先找到你想走的路，再把它变成一个别人愿意点开、读完、记住的网页。
- 右侧票根：今天的三步——翻开职业之书 / 看懂一个网页 / 做出你的网站

### 00 今日目录（文件夹）
- 黄色文件夹，点击打开，7 张纸展开：职业之书、网站案例、三件套、设计原则、提示词、动手实践、作业与总结
- 点任意一张纸 → 翻到那一节；可拖动旋转
- 讲 CSS 时回到这里：「这个 3D 效果全是 CSS 做的」

### 01 职业之书
- 二维码 → 测试页；三步：扫码答题 → 收下鉴定书 → 保存票根（第二节课用）
- 课堂小调查：举手看看全班哪种类型最多
- **测试页说明**：霍兰德 RIASEC 六型，18 题（每种类型各出现 12 次，计分公平）；翻书动效；可随时打开「目录」修改答案；交卷前有检查页；结果为手写鉴定书 + 网站风格票根（风格、60-30-10 配色、首屏重点、结构、可复制的定位提示词）；类型名为霍兰德原名 + 网感昵称。

### 02 网站案例
| # | 网站 | 看点 |
|---|---|---|
| 01 | Sara Youssry · sarayoussry.com | 风格就是第一印象 |
| 02 | Wodniack · wodniack.dev | 技术也可以很好看 |
| 03 | Bruno Simon · bruno-simon.com | 想象力可以有多大（3D 小游戏，课前先打开） |
| 04 | Brittany Chiang · brittanychiang.com | 不花哨也能很专业 |
| 05 | 不二 Esther · hiesther.me | 网站本身就是作品（esther OS 电脑桌面式网站） |
| 06 | 灰条老师 · huali-youxin.pages.dev | 网站也可以有温度和节奏（美术亲手绘制，传递图画、以画会友） |

观察三问：第一眼看到了什么？整体风格是什么？如何组织个人信息、能力和作品？——如果是你，你更想做哪一种？

### 03 交互实验室：网页三件套（5 屏）
1. **开关实验**：HTML / CSS / JS 三个开关，每个开关里有那一层的几行代码。关 CSS → 只剩骨架；关 HTML → 什么都没有；关 JS → 按钮没反应。附：`index.html` 用 `<link>` 和 `<script>` 把另外两个文件拉进来。
2. **点哪里，看代码**：鼠标指向小林网站的任何部分，右侧高亮对应的 HTML 行和 CSS 规则。
3. **动手改一改**：主色、标题字号、圆角、留白、字体；页面和那一行 CSS 实时变化。金句：「你跟 AI 说『标题再大一点』，AI 做的就是改这一行。」
4. **F12 魔法时刻**：五步操作卡；说明只改了自己浏览器里的样子，刷新即恢复。
5. **猜猜是哪一层**：6 道快问快答（按钮变色 / 多了一段介绍 / 点击弹出 / 换成暖色调 / 加一张作品图 / 鼠标放上去图片放大——CSS 也能做简单动效）。

### 课间：素材准备清单
- IP 形象图（可作头像）、1 句个人宣言、3–5 个能力关键词、至少 3 个项目（获奖、课程项目、个人作品）及其图片、邮箱、测试票根上的提示词
- 建好文件夹：`我的网站/index.html` + `我的网站/images/`；图片文件名用英文或数字、不要空格

### 04 五条设计原则（每条：金句 + 改前/改后演示 + 「写进提示词就这么说」）
| 原则 | 演示 | 金句 |
|---|---|---|
| ① 视觉定位 | 同样内容切换理性 / 亲和 / 创意三种气质 | 风格不是装饰，是第一印象 |
| ② 信息层级 | 改前所有字一样大 → 改后有主次；**3 秒测试**：页面闪现 3 秒后遮住，问记住了什么 | **3 秒内，让人知道这是一个什么样的网站、该往哪里看**（已从「看懂你是谁」改为此句，给创意留空间） |
| ③ 用户路径 | 改前模块乱序 → 改后按「我是谁→擅长什么→做过什么→怎么找我」排列并标出路线 | 顺序决定别人怎么理解你 |
| ④ 视觉统一 | 改前 6 种颜色 3 种字体 → 改后 60-30-10 并显示比例条 | 颜色不超过 3 种，字体不超过 2 种 |
| ⑤ 留白对齐 | 留白滑块 + 对齐线开关 | 信息越多，越需要留白和对齐 |

补充提醒：创意布局（如名字藏在花园尽头）完全可以，但首屏要给访客一个「往哪走」的提示。

### 05 提示词工作台（4 屏）
0. **第 0 步：我的网站是一个______**（防止作品趋同）：8 张隐喻卡（花园、地铁线路、游戏存档、展览、电脑桌面、手账、歌单、旅行地图），可点选、随机抽一张或自己写；两个选项：从我的 IP 形象里取色、先要 3 个方向再写代码。
1. **工作台**：顶部切换「基础模式 / 个性模式」。基础模式保证及格；个性模式把隐喻写进提示词，形式规定（卡片、固定顺序）改为推荐，并可加入 IP 取色和「两步生成」。两种模式都加了「避免 AI 模板感」。
   原工作台说明：：填写昵称、专业年级、一句话定位、测试票根提示词、能力标签、3 个项目、图片交互方式、邮箱、创意想法 → 自动生成完整提示词（五条原则、真实性要求、技术要求都已写入）→ 一键复制。
2. **项目卡片怎么写（内容网页化表达）**：同一段 IP 形象设计经历，「一段话」写法 vs「项目卡片」写法。**修改指令卡**：一组可复制的修改指令（标题再大一点、换成暖色调、增加作品区、图片悬停放大、手机适配、检查图片路径……）。
3. **项目不够三个？先挖一挖（课后可选）**：能力盘点多轮对话提示词（基于去年 5-1 的 CRISPE + 十大维度 + STAR + 【待补充】），输出可直接用的项目卡片；链接到独立仓库「能力挖掘教练」（skill + 提示词两种用法，含分专业灵感和真实性自检；skill 已在 4-2 讲过）。

### 06 动手实践 + 自查表
- 课上目标：做出**本地初稿**，课后继续完善
- 步骤：建文件夹 → 复制提示词 → 交给 AI → 保存为 index.html 用浏览器打开 → 用修改指令迭代
- 自查表 9 项（可勾选）：视觉定位 / 3 秒知道往哪看 / 浏览顺序 / 颜色≤3 字体≤2 / 留白对齐 / 不是文字堆砌 / 图片能显示不变形 / 内容真实 / 有一个记忆点

见第 5 节。

## 5. 作业：个人网站

**截止**：讲课后两周（各班按上课时间分别计算），提交**可直接点开的部署链接** + **AI 使用说明**。

### 必备内容（缺一项不算完成）
1. 网页中能**清楚找到**：昵称或姓名、专业年级（如「软件工程 2024 级」）、邮箱——**位置和形式不限**，但要醒目、找得到（不强制放首屏，鼓励创意）
2. 关于我：背景、兴趣、想发展的方向（可参考职业测试结果）
3. 能力标签 3–5 个
4. **至少 3 个项目**：值得讲述的获奖、课程项目或个人作品；每个包含标题、至少 1 张图、2–3 句说明（做了什么 / 用了什么 / 结果）、标签；IP 形象设计可以作为其中之一
5. 至少 1 种图片交互：悬停放大 / 点击看大图 / 轮播 / 作品分类切换

### 技术要求
- 部署后链接能直接打开；手机上能正常浏览
- 图片全部能显示、不变形，使用相对路径 `images/xxx.jpg`
- 浏览器标签页标题是自己的名字或昵称

### 底线
- **内容真实**：AI 可以润色，不能编造经历、奖项和数据
- **隐私**：联系方式只放邮箱；不放手机号、学号、地址；头像用 IP 形象代替真人照片

### 推荐（非必须）
- 页脚加一行 AI 辅助声明，如「本网站在 AI 辅助下完成，内容均为本人真实经历」

### 加分
- 写得好的 README，或清晰的网站使用指引

### AI 使用说明（必交，为期末作业做铺垫）
| 项目 | 内容 |
|---|---|
| 使用的 AI 工具 | 生成网页、生成图片分别用了什么 |
| 迭代过程 | 改了几轮，每轮主要改了什么 |
| 最重要的一条提示词 | 原文照贴 |
| 最满意的地方 | 为什么 |
| 内容来源对照表 | 逐项标注：真实经历 / 自己写的 vs AI 生成 / AI 润色；图片来源（AI 生成 / 自己拍摄 / 网络，网络图片注明出处） |
| 我做出的判断 | AI 给的结果里，我改掉或拒绝了什么，为什么 |
